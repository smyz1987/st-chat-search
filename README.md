# 🔍 聊天全文搜索（chat-search）

在 SillyTavern **首页（聊天列表页）** 一键搜索 **所有角色、所有聊天记录** 的内容，
精确到：**哪个角色 / 哪次聊天 / 第几楼 / 命中片段位置**，点击结果直接跳转到对应消息并高亮。

## 功能
- 多关键词搜索（空格分隔，AND 逻辑）
- **角色筛选（v1.1.0 新增）**：
  - 点击搜索框下方的「角色」选择框展开角色列表
  - **可输入关键词实时搜索角色**（角色多时不用翻）
  - **可多选角色**作为搜索范围（勾选几个只搜这几个）；不选 = 全部角色
  - 已选角色显示为标签，点「×」移除；「全选 / 清空」快捷按钮
- **排除用户消息（v1.1.0 新增）**：勾选后搜索结果不含你自己（user）发的消息，只看角色说的
- **楼层收藏（v1.2.0 新增）**：
  - 搜索结果每条右侧有 ☆，点击收藏该楼层（再点取消），收藏后变 ★
  - 弹窗顶部「⭐ 收藏」页签查看全部收藏（角色 / 聊天 / 楼层 / 片段 / 收藏时间）
  - 点击任意收藏**一键直达**对应楼层并高亮；可单条删除、一键清空
  - 收藏自动保存，重启后还在
- 筛选状态自动记忆（下次打开保持）
- **筛选折叠（v1.3.0）**：角色筛选收进「⚙ 筛选角色」按钮，点击才展开，面板不再臃肿
- **全量角色 + 同名合并（v1.3.0）**：可筛选全部角色（不止有聊天的）；同名角色卡合并成一行（显示"（N 张卡）"），点击一起筛出，再点取消
- **搜索范围/时间优化（v1.3.0）**：未选角色时自动跳过无聊天记录的角色，扫描更快
- **关键词金色高亮（v1.3.0）**：跳转后搜索关键词在消息里呈金色；再次点击同一结果金色消失（可反复开关）
- **角色分组折叠（v1.2.2 新增）**：搜索结果按角色聚合，每组默认展开显示前 6 条命中，点击角色名可折叠/展开
- **分页（v1.2.2 新增）**：每页最多显示 6 个角色分组，支持上一页/下一页、直接输入页码跳转
- **跳转修复（v1.2.2）**：直达后不再因二次渲染跳回 0 楼，稳定停在目标楼层并高亮
- 每个结果展示：角色名 · 聊天时间 · 楼层 · 说话人 · 命中上下文片段
- 命中候选翻页（swipe）时标注「命中第 N/M 条候选」
- 点击结果自动切换角色 → 打开对应聊天 → 定位目标楼层并高亮闪烁
- 兼容「聊天截断显示」设置：自动临时全量渲染找到旧楼层，随后恢复截断并保持目标可见
- 内置缓存（发消息/切换聊天自动失效），重复搜索秒回；「刷新」按钮强制重扫
- 斜杠命令：`/chatsearch 关键词`（别名 `/cs`）

## 安装
把整个 `chat-search` 文件夹放到：
```
data\default-user\extensions\
```
然后**刷新酒馆页面**（手机端也要刷新一次）。无需重启服务、无需改配置。

> 更新版本时如发现还是旧功能，请**强制刷新**（电脑 Ctrl+Shift+R / 手机清除浏览器缓存或刷新页面）。

## 使用
1. 首页"最近的聊天"标题旁点「🔍 搜索聊天内容」按钮（或输入 `/chatsearch 关键词`）
   - 打开某角色的「聊天历史」弹窗时，按钮会跟随显示在弹窗标题行
2. 输入关键词回车
3. 需要时在下方筛选区勾选角色 / 排除用户消息
4. 点击任意结果 → 自动跳转到那条消息并高亮；点结果右侧 ☆ 可收藏该楼层
5. 收藏的楼层在弹窗顶部「⭐ 收藏」页签里，点一下就直达

首次搜索需扫描全部聊天，约 5~15 秒（视聊天数量），之后因缓存秒回。

## 卸载
删除该文件夹，刷新页面即可。

## 说明
- 纯前端实现，调用酒馆内置 `/api/chats/search` + `/api/chats/get`，不修改任何聊天文件。
- 目前支持单角色聊天；群聊搜索为后续版本。
